Dify adalah platform pengembangan aplikasi *Large Language Model* (LLM) sumber terbuka (*open-source*). Antarmukanya yang intuitif menggabungkan *AI workflow*, *pipeline RAG*, kapabilitas agen otonom, manajemen model, fitur observabilitas (termasuk [Opik](https://www.comet.com/docs/opik/integrations/dify), [Langfuse](https://docs.langfuse.com), dan [Arize Phoenix](https://docs.arize.com/phoenix)), dan masih banyak lagi—memungkinkan Anda beralih dari tahap purwarupa (*prototype*) ke produksi dengan cepat.

Berikut daftar fitur utamanya:

## Mulai Cepat (Quick start)

> Sebelum menginstal Dify, pastikan sistem komputer atau server Anda memenuhi spesifikasi minimum berikut:
>
> - CPU >= 2 Core
> - RAM >= 4 GiB

<br/>

Cara termudah untuk menjalankan server Dify adalah menggunakan [Docker Compose](docker/docker-compose.yaml). Sebelum menjalankan perintah berikut, pastikan [Docker](https://docs.docker.com/get-docker/) dan Docker Compose versi v2.24.0 atau yang lebih baru telah terpasang:

```bash
cd dify
cd docker
cp .env.example .env
docker compose up -d
```

Setelah berjalan, Anda dapat mengakses dashboard Dify melalui peramban web di [http://localhost/install](http://localhost/install) untuk memulai proses inisialisasi awal.

#### Bantuan & FAQ

Silakan merujuk ke [FAQ kami](https://docs.dify.ai/getting-started/install-self-hosted/faqs) jika menemui kendala saat pemasangan Dify. Hubungi [komunitas kami](#komunitas--kontak) jika Anda membutuhkan bantuan lebih lanjut.

> Jika ingin berkontribusi pada pengembangan kode Dify, pelajari [panduan instalasi dari source code](https://docs.dify.ai/getting-started/install-self-hosted/local-source-code).

## Fitur Utama

**1. Workflow Visual**:
Rancang dan uji alur kerja AI yang kuat di atas kanvas visual, memanfaatkan seluruh integrasi fitur secara menyeluruh.

**2. Dukungan Model Komprehensif**:
Integrasi mulus dengan ratusan model LLM komersial maupun open-source dari puluhan penyedia inferensi dan solusi *self-hosted*, meliputi GPT, Mistral, Llama 3, serta semua model yang kompatibel dengan OpenAI API. Daftar lengkap penyedia model dapat dilihat [di sini](https://docs.dify.ai/getting-started/readme/model-providers).

![providers-v5](https://github.com/langgenius/dify/assets/13230914/5a17bdbe-097a-4100-8363-40255b70f6e3)

**3. Prompt IDE**:
Antarmuka intuitif untuk meracik *prompt*, membandingkan performa berbagai model secara berdampingan, dan menambahkan fitur interaktif seperti *text-to-speech* ke dalam aplikasi obrolan.

**4. Pipeline RAG (Retrieval-Augmented Generation)**:
Kemampuan RAG lengkap mulai dari ingest dokumen hingga pencarian semantik, dilengkapi dukungan bawaan untuk ekstraksi teks dari PDF, dokumen presentasi PPT, dan berbagai format berkas populer lainnya.

**5. Autonomous Agent**:
Agen mandiri yang beroperasi dalam lingkungan *sandbox* terisolasi: mereka mampu menjalankan perintah, memasang pustaka perangkat lunak, dan memproses dokumen untuk menyelesaikan tugas yang dinamis. Deskripsikan agen yang Anda butuhkan, dan ia akan menyusun dirinya sendiri. Hubungkan alat dari [Dify Marketplace](https://marketplace.dify.ai/?category=tool), server MCP, atau API kustom Anda, lalu terapkan sebagai aplikasi obrolan cerdas atau sebagai langkah otomatis dalam workflow.

**6. LLMOps**:
Pantau dan analisis log riwayat aplikasi serta metrik performanya secara berkala. Anda dapat terus menyempurnakan prompt, dataset, dan model berdasarkan data penggunaan produksi nyata serta anotasi kualitas.

**7. Backend-as-a-Service (BaaS)**:
Seluruh kapabilitas Dify disertai API yang lengkap dan terdokumentasi rapi, memudahkan integrasi fungsionalitas AI ke dalam logika aplikasi backend Anda yang sudah ada.

## Pilihan Penerapan Dify

- **Dify Cloud <br/>**
  Layanan terkelola [Dify Cloud](https://dify.ai) yang dapat langsung dicoba tanpa proses konfigurasi server. Menyediakan seluruh kapabilitas versi mandiri dan mencakup 200 panggilan gratis GPT-4 pada paket *sandbox*. Jika ada kendala, [hubungi tim dukungan Cloud kami](mailto:cloud@dify.ai?subject=%5BGitHub%5DDify%20Cloud%20Support).

- **Self-hosting Dify Community Edition<br/>**
  Jalankan Dify langsung di infrastruktur server mandiri Anda dengan [panduan mulai cepat](#mulai-cepat-quick-start).
  Lihat [dokumentasi resmi kami](https://docs.dify.ai) untuk referensi konfigurasi mendalam.

- **[Dify Enterprise](https://dify.ai/dify-enterprise)<br/>**
  Bagi korporasi atau instansi yang memerlukan dukungan *self-hosting enterprise*, integrasi SSO, keamanan berbasis peran (RBAC), dan SLA dukungan resmi, silakan isi [formulir ini](https://share-na2.hsforms.com/14-09ff5HS92Sh4m3f4yrcw40s9fk) untuk berdiskusi dengan tim representatif kami. <br/>
